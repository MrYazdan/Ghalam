<b>قلم (Ghalam)</b> یک ابزار سریع، مدرن و متمرکز برای نشانه گذاری و ترسیم آزاد روی صفحه نمایش در لینوکس است (بهینه سازی
شده
برای دسکتاپ KDE Plasma، پروتکل Wayland، محیط های X11 و کراس پلتفرم).

با فشردن یک کلید میانبر سراسری، لایه ای شفاف و بدون حاشیه روی صفحه باز می شود. می توانید خطوط آزاد بکشید، متون را با
هایلایتر علامت بزنید، فلش و اشکال هندسی رسم کنید، گام های یک سناریو یا باگ را شماره گذاری کنید (۱، ۲، ۳...) یا یادداشت
متنی تایپ نمایید. با فشردن کلید **`Esc`** همه چیز فوراً پاک شده و برنامه بدون به جا گذاشتن پردازش های اضافی در پس زمینه
خاتمه می یابد.

## امکانات و قابلیت ها

- **مجموعه کامل ابزارهای ترسیم**:
    - **قلم (Pen)**: خطوط نرم با استفاده از منحنی های بزیه (Bézier) و بدون فلیکر (Flicker).
    - **هایلایتر (Highlighter)**:خطوط نیمه شفاف برای مشخص کردن متون و المان های رابط کاربری.
    - **پیکان هوشمند (Arrow)**: رسم فلش های دقیق با نوک هندسی.
    - **اشکال هندسی (Shapes)**: مستطیل هایی با گوشه گرد، دایره/بیضی.
    - **نشانه گذار عددی مراحل (①, ②, ③...)**: ایجاد خودکار دایره های شماره دار افزایشی جهت تولید اسناد و گزارش باگ ها.
    - **ابزار متن (Text)**: کلیک در هر نقطه از صفحه و تایپ مستقیم یادداشت با پس زمینه خوانا.
- **تولبار شیشه ای شناور**:
    - **مخفی بودن پیش فرض**: لایه نقاشی با صفحه کاملا خلوت باز می شود تا بتوانید فورا شروع به کشیدن کنید.
    - **نمایش و مخفی سازی سریع با `Tab` یا `Space`**: پنل شیشه ای تیره (Obsidian Glass) با سایه ملایم که روی پس زمینه
      های کاملا سفید و روشن نیز ۱۰۰٪ خوانا و چشم نواز باشد.
    - امکان جابجایی آزادانه تولبار با درگ کردن ماوس.
    - تنظیم سریع ضخامت قلم با دکمه یا چرخ اسکرول ماوس.
- **پشتیبانی از مانیتورهای چندگانه و مقیاس های مختلف (Fractional Scaling)**:
    - شناسایی خودکار مانیتور فعال از طریق KWin DBus.
    - هماهنگی با مقیاس های ناهمگون (مثلاً ۱۰۰٪ در DP و ۷۵٪ در HDMI).
    - جابجایی فوری لایه بین مانیتورها با کلید **`M`** یا پوشش همزمان تمام مانیتورها با سوئیچ `--monitor all`.
- **بدون پردازش معلق**:
    - با فشردن **`Esc`** یا کلیک روی دکمه ضربدر **`✕`**، حافظه پاک شده و پردازش پایتون فورا متوقف می شود.
    - پشتیبانی کامل از کلیدهای `Ctrl + C` در ترمینال.
- **اشتراک گذاری آسان**:
    - **`Ctrl + C`**: کپی مستقیم اسکرین شات به همراه نشانه ها در کلیپ بورد سیستم (آماده پیست در تلگرام، اسلک، گیت هاب
      و...).
    - **`Ctrl + S`**: ذخیره تصویر نهایی با فرمت PNG در پوشه Screenshots.
- **قدرت گرفته از `uv`**:
    - بدون دغدغه نصب پکیج؛ بالا آمدن در کسری از ثانیه با ثبات کامل نسخه ها (`uv.lock`).

## جدول کلیدهای میانبر

| کلید میانبر                              | عملکرد                                                 |
|:-----------------------------------------|:-------------------------------------------------------|
| **`Esc`** یا **`✕`**                     | **بستن فوری برنامه، پاک سازی کامل و خروج از پردازش**   |
| **`Tab`** یا **`Space`** یا **`V`**      | **نمایش / مخفی کردن پنل ابزار شناور (Toggle Toolbar)** |
| **`P`**                                  | انتخاب ابزار قلم آزاد (Pen)                            |
| **`H`**                                  | انتخاب ماژیک هایلایتر (Highlighter)                    |
| **`A`**                                  | رسم فلش و پیکان جهت دار (Arrow)                        |
| **`R`**                                  | رسم مستطیل با گوشه های نرم (Rectangle)                 |
| **`O`**                                  | رسم دایره و بیضی (Circle)                              |
| **`T`**                                  | ابزار متن (کلیک روی صفحه و تایپ مستقیم)                |
| **`N`**                                  | نشانه گذار عددی گام ها (1, 2, 3...)                    |
| **`1` تا `7`**                           | انتخاب سریع پالت رنگی نئون                             |
| **اسکرول ماوس**                          | افزایش یا کاهش ضخامت خط قلم                            |
| **`M`**                                  | جابجایی لایه بین مانیتورهای متصل (Switch Monitor)      |
| **`Ctrl + Z`**                           | بازگشت به عقب (Undo)                                   |
| **`Ctrl + Y`** یا **`Ctrl + Shift + Z`** | بازگردانی مرحله (Redo)                                 |
| **`C`**                                  | پاک کردن کل صفحه (Clear Canvas)                        |
| **`Ctrl + C`**                           | کپی تصویر صفحه به همراه نقاشی ها در کلیپ بورد          |
| **`Ctrl + S`**                           | ذخیره تصویر نهایی در قالب فایل PNG                     |

## راهنمای راه اندازی و استفاده

### ۱. پیش نیازها

- پایتون نسخه ۳.۱۰ یا بالاتر
- ابزار [uv](https://github.com/astral-sh/uv) (پیشنهادی) یا `python3-venv`

### ۲. نصب و راه اندازی سریع

پروژه را درون مسیر `/opt/ghalam` کلون کرده و اسکریپت نصاب خودکار را اجرا کنید:

```bash
# کلون پروژه در /opt/ghalam
sudo git clone https://github.com/mryazdan/ghalam.git /opt/ghalam
sudo chown -R $USER:$USER /opt/ghalam

# اجرای نصاب
cd /opt/ghalam
./setup.sh
```

نصاب خودکار (`setup.sh`) کلیه مراحل را به صورت هوشمند انجام می دهد:
1. دستور ترمینالی `ghalam` را در مسیر `~/.local/bin/ghalam` لینک می کند.
2. آیکون ها و فایل دسکتاپ اینتری را در سیستم نصب و ثبت می کند.
3. میانبر سراسری دسکتاپ را تنظیم می کند (پیش فرض: **`Meta + Shift + A`**).

#### میانبر سفارشی (اختیاری)

می توانید کلید میانبر دلخواه خود را نیز هنگام نصب تعیین کنید:

```bash
./setup.sh "F8"
# یا
./setup.sh "Ctrl+Alt+A"
```

### ۳. نحوه اجرای قلم (Ghalam)

پس از نصب، می توانید از هر کجای سیستم به راحتی قلم را اجرا کنید:

1. با فشردن کلید میانبر (**`Meta + Shift + A`**)
2. با تایپ دستور **`ghalam`** در هر ترمینال
3. با جستجوی نام **Ghalam** یا **قلم** در منوی برنامه های دسکتاپ

*(همچنین برای اجرای پرتابل و بدون نیاز به نصب میانبر، می توانید مستقیماً از دستور `./run.sh` استفاده کنید)*

## پشتیبانی از چند نمایشگر

قلم به طور خودکار مانیتور فعال شما را شناسایی میکند. همچنین می توانید مانیتور هدف را مشخص کنید:

```bash
# باز کردن همزمان روی تمام مانیتورهای متصل:
ghalam --monitor all

# اجبار به باز شدن روی مانیتور HDMI یا DP:
ghalam --monitor hdmi
ghalam --monitor dp
```
